# قسم «الكتاب المقدس» — البيانات والتوثيق

هذا المجلد يحتوي على كل بيانات قسم **الكتاب المقدس** في موقع كنيسة الأنبا بيشوي.
القسم للقراءة فقط — لا يكتب في أي قاعدة بيانات ولا يستخدم أي خدمة خارجية.

## البنية

```
bible/
├── bible.js         كود القسم: التحميل الكسول + البحث + صفحات العرض (يُحمّل في index.html)
├── metadata.json    فهرس الأسفار الـ66 (الاسم، العهد، عدد الإصحاحات والآيات، الترتيب القبطي)
├── ot/              39 ملفًا — نص العهد القديم كاملًا (ملف لكل سفر)
├── nt/              27 ملفًا — نص العهد الجديد كاملًا (ملف لكل سفر)
├── tafsir/          66 ملفًا — هيكل التفسير (حالة pending حتى يُضاف المحتوى)
└── README.md        هذا الملف
```

## مصدر النص والترخيص

- **الترجمة:** الكتاب المقدس — ترجمة سميث وفاندايك (Smith & Van Dyck 1865).
- **الحالة القانونية:** ملكية عامة (Public Domain).
- **المصدر الرقمي:** مستودع `BibleAquifer/ArabicVanDyckBible` على GitHub
  (ملفات USFM، مرخّصة Public Domain CC0) — تم التحويل منها آليًا بدون أي
  تعديل على النص (فقط إزالة وسوم USFM وتقسيم الأسفار/الإصحاحات/الآيات).
- **التحقق:** 66 سفرًا · 1189 إصحاحًا · 31104 آية — كل الأرقام متسلسلة
  وكل إصحاح مطابق للعدد المعروف (التكوين 50، المزامير 150... إلخ).
- **الترتيب:** الترتيب القبطي الأرثوذكسي للأسفار الـ66
  (مطابق لترتيب الفاندايك في هذه الأسفار — الفروق القبطية تخص الأسفار
  القانونية الثانية فقط وهي غير مشمولة حسب القرار المعتمد).

## صيغة ملفات الأسفار (ot/*.json و nt/*.json)

```json
{
  "id": "gen",
  "name": "التكوين",
  "testament": "ot",
  "translation": "الكتاب المقدس — ترجمة سميث وفاندايك (1865) — ملكية عامة",
  "source": "BibleAquifer/ArabicVanDyckBible — Public Domain (CC0)",
  "chapters": [
    ["آية 1 من الإصحاح 1", "آية 2", "..."],
    ["آية 1 من الإصحاح 2", "..."]
  ]
}
```

- `chapters[i][j]` = الآية رقم `j+1` من الإصحاح رقم `i+1` (الترقيم ضمني بالموضع).
- الموقع يُحمّل ملف سفر واحد فقط عند فتحه (تحميل كسول + ذاكرة مؤقتة).

## صيغة ملفات التفسير (tafsir/*.json) — لإضافة المحتوى لاحقًا

الملفات الحالية هياكل فارغة (`"status": "pending"`). عند توفر نص تفسير
من مصدر تملك الكنيسة حق استخدامه، يُستبدل محتوى الملف بهذه الصيغة:

```json
{
  "bookId": "gen",
  "status": "ready",
  "source": "اسم المصدر (يُعرض في الصفحة)",
  "chapters": [
    {
      "chapter": 1,
      "sections": [
        { "verses": "1-3", "title": "عنوان اختياري", "text": "نص التفسير..." },
        { "verses": "4-5", "text": "نص التفسير..." }
      ]
    }
  ]
}
```

- `verses`: نطاق الآيات التي يشرحها المقطع (نص حر، مثال: `"1-3"` أو `"1"`).
- `title`: اختياري.
- `text`: نص التفسير — يُعرض كما هو (سطر جديد = سطر جديد).
- البحث يشمل التفسير تلقائيًا فور وجود محتوى `ready` — بدون أي تعديل في الكود.

## المسارات (Routes)

```
#/bible                 الصفحة الرئيسية (العهد القديم / العهد الجديد / التفسير / البحث)
#/bible/ot              أسفار العهد القديم
#/bible/nt              أسفار العهد الجديد
#/bible/book/<id>       إصحاحات السفر
#/bible/read/<id>/<ch>  نص الإصحاح (مع ?v= لتظليل آية قادمة من البحث)
#/bible/tafsir           فهرس التفسير
#/bible/tafsir/<id>      تفسير سفر (إصحاحاته)
#/bible/tafsir/<id>/<ch> تفسير إصحاح
#/bible/search           البحث في الكتاب والتفسير (نطاقات: الكل/القديم/الجديد/التفسير)
```
