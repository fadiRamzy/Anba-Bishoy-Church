# دليل خدام ومخدومي كنيسة الأنبا بيشوي - المنيا الجديدة

نظام إدارة بيانات ثابت (Static)، بدون سيرفر أو قاعدة بيانات خارجية. كل البيانات
مخزّنة داخل متصفح كل جهاز عبر **IndexedDB**.

## التشغيل محليًا
افتح `index.html` مباشرة، أو شغّل سيرفر بسيط:
```
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد لريبو GitHub.
2. من إعدادات الريبو → Pages → اختر الفرع (main) والمسار (root).
3. الموقع هيبقى متاح على `https://<username>.github.io/<repo>/`.

لا يوجد أي مفاتيح أو أسرار في الكود — آمن للنشر العام.

## تخزين البيانات
- أول مرة يفتح فيها أي حد الموقع، بيتحمّل تلقائيًا 99 اسم من `data/seed.json`
  (بيانات مرحلة الحضانة من ملف Excel الأصلي) داخل IndexedDB الخاصة بالمتصفح.
- بعد كده كل إضافة/تعديل/حذف بيحصل محليًا على نفس الجهاز بس.
- **البيانات مش متزامنة بين الأجهزة تلقائيًا.** لنقل البيانات لجهاز تاني
  (أو من الكمبيوتر للموبايل)، استخدم صفحة **إدارة البيانات** (`#/admin`):
  - **تصدير:** يحمّل ملف JSON فيه كل البيانات.
  - **استيراد:** يرفع نفس الملف على جهاز تاني (بخيار الدمج أو الاستبدال الكامل).
- يُنصح بعمل تصدير دوري كنسخة احتياطية.

## الحماية
مفيش نظام تسجيل دخول حقيقي (الموقع Static بالكامل بدون backend). بدل كده،
أي عملية إضافة/تعديل/حذف بتطلب **رمز إدارة (PIN)** محلي:
- أول مرة حد يحاول يعدّل، هيتطلب منه تعيين رمز (4 أرقام على الأقل).
- الرمز نفسه (كـ hash) بيتخزن جوه IndexedDB بتاعة نفس الجهاز.
- ده حماية أساسية بس (تمنع التعديل بالغلط)، مش حماية أمنية حقيقية — أي حد
  عنده وصول فعلي للجهاز والمتصفح يقدر يمسح الـ IndexedDB ويعيد تعيين رمز جديد.

## هيكل الملفات
```
index.html          الصفحة الرئيسية (shell)
css/styles.css       التصميم
js/db.js             طبقة IndexedDB (CRUD + بحث + تصدير/استيراد)
js/app.js            التوجيه (routing) وكل الواجهات
data/seed.json        بيانات الإدخال الأولي (من Excel، مرة واحدة فقط)
assets/logo.jpg       شعار الكنيسة
```

## ملاحظة عن نطاق البيانات الحالية
ملف Excel الأصلي ("الافتقاد العام - ابتدائي") يحتوي فعليًا على 99 اسم فقط،
كلهم تحت: القطاع = حضانه (KG1/KG2)، مرحله = مدارس_الأحد، المدينة = المنيا
الجديدة. باقي المراحل (ابتدائي، إعدادي، ثانوي، جامعة، خريجين...) هتتضاف
لاحقًا عن طريق واجهة "إضافة اسم" أو استيراد ملفات بيانات جديدة — والنظام
مصمم يستوعبها تلقائيًا بدون أي تعديل في الكود.
