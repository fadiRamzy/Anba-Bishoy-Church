# التقويم الكنسي — Coptic Orthodox Church Calendar module

وحدة مستقلة داخل قسم «الكتاب المقدس» — تعمل بالكامل داخل المتصفح
(لا خادم، لا خدمات خارجية، لا اعتماديات)، ومتوافقة مع GitHub Pages.

## الملفات

| الملف | الوظيفة |
|---|---|
| `coptic-calendar.js` | محرك التحويل والحساب + عرض صفحة `#/bible/calendar` |
| `calendar.css` | تنسيقات الوحدة فقط (لا يمس `styles.css`) |
| `data/feasts-fixed.json` | الأعياد الثابتة بالتاريخ القبطي (19 عيدًا) |
| `data/feasts-movable.json` | الأعياد المتنقلة محسوبة من عيد القيامة + المواسم |
| `data/saints.json` | التذكارات الثابتة + التذكارات الشهرية المتكررة |
| `data/fasts.json` | فترات الأصوام الخمسة (الحدود والقواعد) |
| `data/readings.json` | قراءات موثقة مختارة (مستوى الإصحاح فقط) |

## قاعدة الحساب

- التحويل قبطي ↔ ميلادي عبر رقم اليوم اليولياني (JDN)، والحقبة:
  1 توت 1 ش. = 29 أغسطس 284 (تقويم يولياني)، والتحقق: 1 توت 1738 = 11 سبتمبر 2021.
- السنة القبطية كبيسة (6 أيام للنسيء) عندما `year % 4 === 3`، ورأس السنة
  11 سبتمبر (12 سبتمبر بعد السنة الكبيسة).
- عيد القيامة بخوارزمية Meeus للتقويم اليولياني ثم التحويل للميلادي —
  مدقق 2021–2031 مع timeanddate وdatetimeonline وholidays-info.
- كل المتنقلات إزاحات أيام من القيامة (E): رفاع يونان E-70، صوم يونان
  E-69..E-67، فصح يونان E-66، رفاع الصوم E-56، الصوم الكبير E-55..E-1،
  الآحاد E-49..E-14، سبت لعازر E-8، الشعانين E-7، خميس العهد E-3،
  الجمعة العظيمة E-2، سبت النور E-1، شم النسيم E+1، أحد توما E+7،
  الصعود E+39، العنصرة E+49، صوم الرسل E+50..11 يوليو —
  وكلها مدققة مع جدول st-takla لسنة 1738 (2021–2022).
- عيدا الميلاد (7 يناير) والغطاس (19 يناير) مثبتان على الميلادي —
  الكنيسة تحتفل بهما في هذين اليومين دائمًا (الميلاد = 28 كيهك في
  السنة الكبيسة). باقي الثوابت مثبتة على التاريخ القبطي.
- البرامون (للميلاد والغطاس فقط): العيد الأحد ← جمعة+سبت، العيد
  الاثنين ← جمعة+سبت+أحد، غير ذلك ← اليوم السابق فقط.
- الصوم الأربعاء والجمعة أسبوعيًا ما عدا الخمسين المقدسة (E..E+49)
  وعيدي الميلاد والغطاس (يفطران تمامًا)؛ العيد السيدي الصغير في
  الأربعاء/الجمعة يكسر الانقطاع فقط.
- أصوام الدرجة الأولى (بدون سمك): الصوم الكبير، يونان، الأربعاء
  والجمعة، البرامون. الدرجة الثانية (سمك ما عدا الأربعاء والجمعة):
  الميلاد والرسل والعذراء.
- التذكار الشهري يوم 29 (الأعياد السيدية الثلاثة) لا يُحتفل به في
  طوبه وأمشير.

## المصادر

- النتيجة القبطية السنوية والأعياد الثابتة/المتنقلة:
  https://st-takla.org/feasts/calendar/ar/years/1738-2021-2022.html
- الأعياد السيدية الكبرى والصغرى:
  https://copticwave.org/taks/taks_feasts/taks_feasts_abona_ashia_003.htm
- السنكسار (تواريخ القديسين): https://st-takla.org (قسم السنكسار)،
  https://www.copticchurch.net/synaxarium/?lang=ar
- جدول القيامة: https://www.timeanddate.com/holidays/egypt/coptic-easter-day
- صوم الرسل والبرامون والخمسين ودرجات الأصوام: اليوم السابع، الدستور،
  الوطن، المصري اليوم، صوت الأمة، الفجر (تقارير 2017–2026).

## حدود معروفة

- القراءات مختارة وموثقة فقط (آحاد الصوم، يونان، سبت لعازر) — ليست
  قطمارسًا كاملًا.
- الاستثناءات الغذائية التفصيلية للأعياد داخل الأصوام (كعيد البشارة
  في الصوم الكبير) تُترك لإعلان الكنيسة.
- في السنوات التي لا يوافق فيها الرفاع الثابت يوم أحد يُرجى مراجعة
  إعلان الكنيسة الأرثوذكسية.
